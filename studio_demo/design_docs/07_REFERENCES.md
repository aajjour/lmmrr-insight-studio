# 7 — Sources checked 30 October 2026

1. Bani-Mustafa, A., and Al-Nasser, A. D. (2026). *Indexed recursive residual processes for diagnostic assessment of linear mixed models.* Journal of Statistical Computation and Simulation. https://doi.org/10.1080/00949655.2026.2748404. Publisher describes plug-in Cholesky innovation residuals, meaningful indexed processes, centred model-specific Gaussian-process limit, refit-bootstrap calibration, 16 misspecification scenarios, and examples from BodyWeight, sleepstudy, Pastes, Produc.
2. CRAN Repository Policy. https://cran.r-project.org/web/packages/policies.html. Explicitly limits concurrent package checking to two cores and recommends small tarballs and light examples/tests.
3. R Core Team, *Writing R Extensions.* https://cran.r-project.org/doc/manuals/r-devel/R-exts.html. `R CMD build`, `R CMD check --as-cran`, package metadata, manual pages, examples and citations.
4. Posit, *Welcome to Shiny.* https://shiny.posit.co/r/getstarted/shiny-basics/lesson1/. Official interactive R application documentation.
5. Hartig et al., *DHARMa: Residual Diagnostics for Hierarchical (Multi-Level / Mixed) Regression Models.* https://florianhartig.github.io/software/dharma/. Related residual diagnostic package; illustrates calibration and differential limitations; not interchangeable with published LMM RR method.

The prototype's interpretation rules are **hypotheses proposed for validation** and are not attributed to any source as already validated misspecification-classification theory. The study design in `06_SECOND_PAPER.md` is prospective and not yet executed.
